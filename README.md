# Content Machine (MineHash) — Платформа для автоматизации контента

CONTENT MACHINE — это мощный инструмент на базе ИИ для автоматического создания, обработки и публикации видео-контента и каруселей.

## 🛠 Интегрированные сервисы

Система объединяет лучшие API для работы с медиа:

*   **Apify**: Скрапинг контента из соцсетей (YouTube, Shorts и др.). Позволяет автоматически «вытягивать» новые видео с каналов.
*   **Vizard.ai**: ИИ-сервис для автоматического нахождения виральных моментов в длинных видео и нарезки их на короткие клипы (Shorts/Reels).
*   **Deepgram**: Сверхбыстрое и точное распознавание речи (STT) для создания субтитров и транскрипций.
*   **ElevenLabs**: Профессиональное озвучивание текстов (TTS). Используется для дубляжа контента на разные языки с сохранением эмоций.
*   **Gemini (Google)**: Анализ текстов, оценка виральности и генерация сценариев (через OpenRouter).
*   **Kie.ai**: Генерация изображений для каруселей и рекламных плашек с использованием модели `nano-banana-pro`. 
*   **AIHubMix**: Резервный сервис для генерации изображений (Gemini 3.1 Flash Image), если основной сервис недоступен.
*   **AWS S3**: Хранилище для всех медиафайлов (видео, превью, шрифты).
*   **Telegram Bot**: Главный интерфейс взаимодействия. Через бота пользователи получают уведомления и управляют процессом.
*   **BullMQ / Redis**: Система очередей для фоновой обработки тяжелых задач (рендеринг видео, загрузка).

## ⚙️ Настройка окружения (.env)

Для работы приложения необходимо создать файл `.env` в корневой папке. Основные параметры:

### Базовая конфигурация
*   `PORT=3000`: Порт, на котором будет работать сервер.
*   `DATABASE_URL`: Строка подключения к базе данных PostgreSQL.

### API Ключи сервисов
*   **`OPENROUTER_API_KEY`**: Основной ключ для доступа к нейросетям (используется модель `gemini-2.0-flash`). Отвечает за логику ИИ.
*   **`KIE_API_KEY`**: Ключ для генерации картинок через Kie.ai.
*   **`AIHUBMIX_API_KEY`**: Резервный ключ для генерации картинок (Gemini Image).
*   `APIFY_TOKEN`: Токен для скрапинга YouTube через Apify.
*   `VIZARD_API_KEY`: Ключ Vizard.ai для автоматической нарезки клипов.
*   `DEEPGRAM_API_KEY`: Ключ для работы с аудио и субтитрами.
*   `ELEVEN_LABS_API_KEY`: Ключ для синтеза речи (дубляжа).

### Telegram
*   `TELEGRAM_BOT_TOKEN`: Токен вашего бота от BotFather. Нужен для отправки уведомлений и обработки команд.
*   `VITE_TELEGRAM_BOT_USERNAME`: Username бота без символа @.

### Администраторы
*   `ADMIN_TELEGRAM_ID` или `ADMIN_TELEGRAM_IDS`: Telegram ID пользователей, которые будут иметь права администратора (можно через запятую).

### Хранилище S3
*   `S3_ENDPOINT`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_BUCKET_NAME`: Данные для подключения к облачному хранилищу (например, AWS или DigitalOcean/MinIO).

---

Система использует **BullMQ** для параллельной обработки задач. Вы можете управлять нагрузкой через одну переменную в `.env`:

*   `WORKER_CONCURRENCY`: Количество параллельных задач. 
    *   `1` — для слабых серверов (1 CPU / 2GB RAM).
    *   `10-20+` — для мощных серверов (30+ CPU). Можно увеличивать, пока хватает оперативной памяти и лимитов внешних API.

## 👤 Роли и функционал

### Администратор
Обладает полным контролем над системой:
*   **Управление пользователями**: Авторизация новых пользователей, удаление, назначение других администраторов.
*   **Глобальные настройки**: Управление лимитами обработки видео и глобальными API ключами.
*   **Статистика**: Просмотр детальной аналитики по всем каналам, видео и публикациям в системе.
*   **Контроль контента**: Доступ ко всем созданным клипам и истории публикаций.

### Пользователь
Работает со своим контентом:
*   **Управление каналами**: Добавление своих YouTube-каналов для мониторинга.
*   **Обработка**: Запуск процессов нарезки видео, озвучки и наложения водяных знаков.
*   **Карусели**: Создание стилизованных каруселей на основе ИИ-анализа.
*   **Публикация**: Отправка отчетов о публикациях и управление собственным архивом.

## 🚀 Быстрый запуск

### С помощью Docker (Рекомендуется)
Все сервисы (App, PostgreSQL, Redis) настроены в `docker-compose.yml`.

1.  Настройте `.env` на основе `.env.example`.
2.  Запустите всё одной командой:
    ```bash
    docker-compose up -d --build
    ```

### Локальный запуск (без Docker)
1.  Установите зависимости: `npm install`
2.  Убедитесь, что у вас установлен и запущен **Redis** (порт 6379) и **PostgreSQL**.
3.  Запустите сервер: `npm run dev`
